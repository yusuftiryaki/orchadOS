# Kitin saati PPS'siz (USB zamanı) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The kit's clock counts as locked when chrony follows the receiver's USB time (latency-corrected), not only with PPS.

**Architecture:** chrony selects the `GNSS` SOCK refclock with `offset 0.055`; PPS stays preferred when wired. The recorder gets a `usb` clock state (code 1, replaces `coarse`) and treats `pps` or `usb` as "locked" everywhere it used `pps`; the pipeline and the field app accept `usb`. `gnss-check` measures the USB latency against the system clock.

**Tech Stack:** Python 3.12 (kit-recorder, pipeline; pytest, ruff), chrony, Flutter/Dart (field app).

**Spec:** `docs/superpowers/specs/2026-11-20-usb-saat-design.md`

## Global Constraints

- USB latency: `CHRONY_USB_OFFSET_MS = 55`; chrony line carries `offset 0.055`.
- `usb` requires: chrony reference `GNSS`, leap status synchronised, estimated error ≤ `CLOCK_USB_MAX_ERROR_US = 5000`, where error = |system offset| + root delay / 2 + root dispersion.
- Status byte 54: 0 unlocked, 1 `usb`, 2 `pps`. String value `usb` in `recording.json` / `session.json` `clock_state_at_start`.
- Anchor columns (`pps_esp_micros`, `pps_gps_time_ns`) only with `pps`; empty with `usb`.
- Event names `pps_lost` / `pps_regained` unchanged; they now mean loss and return of the lock (`pps` or `usb`).
- Code, identifiers, comments in English; `docs/` in Turkish.

## Review Focus

1. chrony has selected GNSS but has not converged (error 12 ms just after boot) → `unlocked`, pre-check `clock` fails. Test in Task 1.
2. Lock drops from `usb` to `unlocked` mid-session → `pps_lost` event and `clock_unlocked` alert; back → `pps_regained`. Test in Task 2.
3. `usb` session: `events.csv` rows carry `gps_time_ns` with both anchor columns empty, and the pipeline reads them as is. Test in Task 4.
4. A NAV-PVT on a full second (`iTOW % 1000 == 0`) or without resolved time sends no chrony sample. Test in Task 1.
5. PPS wired later: reference `PPS` within 1 ms and fresh edge → `pps` with an anchor, as today (existing tests must keep passing unchanged).
