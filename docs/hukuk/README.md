### Bilinen fark (İP14 dışı)

23. **Karara bağlandı:** [H24](kararlar.md#h24) — metin sisteme uyduruldu. **Ödenmeyen sipariş.** Sözleşme (Md. 8/2) ve iade politikası (1. bölüm) "ödeme süresi içinde ödenmeyen sipariş kendiliğinden düşer" diyor; sistem ise süre dolunca siparişi iptal etmiyor, yalnızca hatırlatma gönderiyor (`docs/musteri-yonetimi.md` §5.3).
